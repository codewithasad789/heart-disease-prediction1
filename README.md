# Heart Disease Prediction

## Objective
Predict heart disease using ML models to assist early detection.

## Dataset
Cleveland Heart Disease dataset - 303 patients, 13 features.  
Target: 0 = No Disease, 1 = Disease Present.

## Models Applied
1. Logistic Regression
2. Decision Tree Classifier

## Results
| Model | Accuracy |
| --- | --- |
| Logistic Regression | 85.25% |
| Decision Tree | 81.97% |
